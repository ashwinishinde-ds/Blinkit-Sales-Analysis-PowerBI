## 📊 Project Overview

This project is an interactive **Blinkit Sales Analysis Dashboard** created using **Microsoft Power BI**.

The dashboard provides insights into sales performance, orders, products, delivery status, payment methods, ratings, and geographical sales distribution.

## 🎯 Objectives

* Analyze overall sales performance
* Track monthly sales trends
* Identify top-performing products
* Analyze delivery status
* Compare sales across locations/areas
* Analyze payment methods
* Monitor average sales and ratings
* Build an interactive business intelligence dashboard
